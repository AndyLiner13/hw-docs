# [FocusedInteractionTrailOptions type](#focusedinteractiontrailoptions-type)

The [FocusedInteraction](../Classes/FocusedInteraction.md) options for visual trails that are displayed when players use swipe and drag input.

## [Signature](#signature)

```ts
export declare type FocusedInteractionTrailOptions = {
    length: number;
    startWidth: number;
    endWidth: number;
    startColor: Color;
    endColor: Color;
    startOpacity: number;
    endOpacity: number;
};
```
