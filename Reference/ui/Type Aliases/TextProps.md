# [TextProps type](#textprops-type)

Represents the props of a [text](../Functions/Text_2.md) component.

## [Signature](#signature)

```ts
export declare type TextProps = {
    text: Bindable<string | LocalizableText>;
    numberOfLines?: number;
    style?: TextStyle;
};
```
