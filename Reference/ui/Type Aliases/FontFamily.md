# [FontFamily type](#fontfamily-type)

Defines the available fonts for a [Text](../Functions/Text_2.md) component in a UI panel.

## [Signature](#signature)

```
export
 declare type 
FontFamily
 
=
 
'Anton'
 
|
 
'Bangers'
 
|
 
'Kallisto'
 
|
 
'Optimistic'
 
|
 
'Oswald'
 
|
 
'Roboto'
 
|
 
'Roboto-Mono'
;
```

## [Remarks](#remarks)

For descriptions of the available styles, see [Custom UI Styles](../../../Desktop%20editor/Custom%20UI/Custom%20UI%20Styles.md#textstyle).
