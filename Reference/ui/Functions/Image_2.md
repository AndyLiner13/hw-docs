# [Image\_2() Function](#image_2-function)

Creates an Image component for a UI panel.

## [Signature](#signature)

```ts
export declare function Image(props: Readonly<ImageProps>): UINode<ImageProps>;
```

## [Parameters](#parameters)

props: Readonly<[ImageProps](../Type%20Aliases/ImageProps.md)>

The props of the Image component.

## [Returns](#returns)

[UINode](../Classes/UINode.md)<[ImageProps](../Type%20Aliases/ImageProps.md)>

A `UINode` object representing the Image component.

## [Remarks](#remarks)

You can use the [ImageSource](../Classes/ImageSource.md) class to define the source of an image asset. For information about usage, see the [Image from Asset](https://developers.meta.com/horizon-worlds/learn/documentation/tutorials/tutorial-worlds/custom-ui-examples-tutorial/station-2-image-from-asset) section of the Custom UI Examples tutorial.
