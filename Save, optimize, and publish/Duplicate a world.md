# [Duplicate a world](#duplicate-a-world)

## [To duplicate a world:](#to-duplicate-a-world)

1. From your **Personal Menu**, select the **Create** icon.
2. Select **Drafts**, then select the world’s thumbnail photo.
3. Select the **Three Dot** icon, then select **Duplicate**.

Keep in mind, you can only duplicate a world if you’re the original creator.

[Learn more](Permissions%20when%20you%20add%20a%20collaborator%20to%20your%20world.md) about collaborators and duplicating worlds.
