# [Creating, Editing, Removing, and Moving Assets to Folders](#creating-editing-removing-and-moving-assets-to-folders)

## [Creating folders](#creating-folders)

To create a new folder, click the “Add New” menu button above the left navigation column and select “Folder”. ![](../../.assets/gifs/7193b46a7325e1eaeb81ae0e658286d5be826a5aae7f8fbece36d54160b2fdbc.gif)

## [Editing folders](#editing-folders)

1. To rename a folder, right-click the folder in the left navigation column and select “Edit”. ![](../../.assets/gifs/f6a1c2660d45dd27cad4d774bca17abf1828bcf25e72503d5b53ff744a107320.gif)
2. Fill out the Edit Folder fields and then click “Update” to finalize your changes.

## [Removing folders](#removing-folders)

To remove a folder from your library, right-click the folder in the left navigation column and select “Remove”. ![](../../.assets/gifs/632962a0dc9dddd1489709225f9222e802cb08aa0ef2937ef765e24537366913.gif)

> [!Note]
>
> When deleting a folder, any assets inside will be moved into the “Removed Assets” folder.

## [Moving assets to different folders](#moving-assets-to-different-folders)

To move an asset into a different folder, right-click the asset card  and select “Move” and then fill out the modal dialog. ![](../../.assets/gifs/382fdd126b3295241499cd0090146da993428cba6c2198a322d39a3064b9438a.gif)
