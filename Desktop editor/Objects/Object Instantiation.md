# Object Instantiation

- Click on the “Build” box icon from the top bar.
  ![](../../_assets/images/4bc963c92854102d553533e2f4c67a6e4f8c512b60e5beb3e0b98885fdf01e24.png)
- Selecting shapes, gizmos, sounds from the drop-down menu will display 3D objects.
  ![](../../_assets/images/0d0544db45d303409ac0b3187b5c3e54c9f3cc0b31d883d41f7598f116612a63.png)
- When the user clicks on a 3D object, the object is spawned in the world.
  ![](../../_assets/images/33eaabd2791ee85d4b28dca47a66d164196fea99ff62ae409420f07f916dda6e.png)
