# Renaming Objects

This feature enables you to rename objects and gizmos in the hierarchy, so they are easy to find later.

![renamed.gif](../../_assets/gifs/9369cd66eab241fb8809cc3e5300b8bd4fec83a417d811e65d7882afd795ca59.png)

Follow these steps to rename objects in the hierarchy:

- Select any entity in the world (*single left click*).
  ![](../../_assets/images/99a0d08a2c214fadeb677f046f183c844ab3a3f1b667debf299fa1e9dac0a354.png)
- Click on the selected entity again (*single left click*) or Press F2.
  ![](../../_assets/images/f93dfa8cd97bcf30ce9cc4fa17098d9b1b5a910131c5ecad8e31cba5caa81f87.png)
  You can also right click and select **Rename** from the popup menu.
  ![Rename option from right click menu](../../_assets/images/c1c4a9c14c6b5a8a66470b3ed7187de702bf5ad11158b4224568fec91be04ca6.png)
- Type in the new name.
  ![](../../_assets/images/8ac321bb7d18c721fc00f4879aa55a84795c24b2580f92b9e584a8560878704c.png)
- Press Enter or unfocus the text input to save.
  ![](../../_assets/images/f515b499861e4d096e2e506e2317f834d76cac9a90970be85fb78b293e57a592.png)
