# [Introduction to game creation video series](#introduction-to-game-creation-video-series)

Learn the basics of designing a viable game in this series of tutorials. Game designer Andy Sargeant provides guidance in the following videos.

### [What you’ll learn](#what-youll-learn)

- **Game loops:** Understand the heartbeat of engaging games.
- **Mobile mechanics:** Adapt your designs for mobile platforms.
- **Retention strategies:** Keep your players coming back.
- **Metagame considerations:** Add depth and long-term goals.
- **And more:** Learn how to create a game that players will love.
